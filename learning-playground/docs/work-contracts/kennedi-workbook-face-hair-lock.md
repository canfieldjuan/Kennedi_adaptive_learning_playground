# Kennedi Workbook: Lock Kennedi's Face and Hair Across the 8 Locked Poses

Owner review (2026-09-24) of the consistency sheet: "the faces and some
features are different among the different pictures." Supersedes PR #140
(sheet refresh only), whose build script is folded in here.

## Before Code

### Root Cause

The eight locked Boss Kennedi poses
(`workbook/design-source/boss-kennedi/locked-poses/0[1-8]-*.png`) show eight
similar girls, not one. At matched face width the eyes vary (small dots,
large glossy, heavy-lashed), the nose (none, curve, prominent "c",
freckled), bangs (curtain, swept, center part, spiky), pigtails (curly,
long straight, short high puffs), and apparent age.

Cause: the pipeline asks one knob, FLUX.1 Redux strength, to carry both
pose change and identity. `asset-provenance.md` records that strength >=0.2
snaps poses back to the standing reference, so posture changes run at
~0.08 -- where Redux transfers style and outfit but almost none of the
face, so FLUX invents a new face each time. The #139 audit that called 6 of
7 poses consistent scored trait *presence* (has pigtails, has eyelashes),
which this failure passes; it did not compare faces.

Fix, prototyped and owner-approved (scratch, 2026-09-24): separate the two
jobs. Keep every pose as drawn and repaint only the head (face, hair,
pigtails) against one canonical head, by FLUX.1 Fill "in-context"
(canonical on the left half of one canvas, target on the right, target
head masked), composited back through the feathered head mask. Canonical
(owner pick): pose 07 with its face repainted by Fill + Redux 0.6 (seed 2)
from the 01 head. Head-only Redux at that strength does not disturb the
pose, because the pose is not regenerated.
